Vigil {{ .Chart.AppVersion }} is installed as release "{{ .Release.Name }}" in namespace "{{ .Release.Namespace }}" (environment: {{ .Values.environment }}).

Watch the pods start:
  kubectl get pods -n {{ .Release.Namespace }} -w

{{- if .Values.ingress.enabled }}

Open the UI (k3d maps host port 8081 to the cluster's ingress):
  http://{{ .Values.ingress.hosts.app }}:8081
{{- if .Values.demoShop.enabled }}
Demo shop and its admin panel:
  http://{{ .Values.ingress.hosts.demo }}:8081/admin
{{- end }}
{{- end }}

Check that the api is ready (database + redis + schema):
  helm test {{ .Release.Name }} -n {{ .Release.Namespace }}

Every watch you create gets its own CronJob:
  kubectl get cronjobs -n {{ .Release.Namespace }} -l app.kubernetes.io/managed-by=vigil-api

{{- if .Values.worker.autoscaling.enabled }}
Workers are scaled by KEDA ({{ .Values.worker.autoscaling.minReplicas }}..{{ .Values.worker.autoscaling.maxReplicas }} pods) on the Redis list "vigil:checks":
  kubectl get scaledobject,hpa -n {{ .Release.Namespace }}
{{- end }}
